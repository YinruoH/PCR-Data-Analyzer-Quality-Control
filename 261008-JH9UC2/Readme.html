PCR导出文件可视化分析工具 by HZC

这是一款用于查看和初步分析实时荧光定量 PCR（qPCR）导出结果的本地工具。它可以把表格重新显示为 96 孔板，整理 Ct 和相对表达量，标出可疑孔位，辅助检查技术复孔，并在剔除异常孔后重新计算结果。

第一次使用时，建议先阅读第 1～4 节；需要处理异常数据时，再阅读第 5～8 节。

01

先了解这个工具能做什么

日常使用 qPCR 仪器时，软件导出的 Excel 文件通常包含很多行数据。例如，同一个样本检测多个基因，每个基因做 3 个技术复孔。直接在原始表格中逐行寻找问题，容易看漏。

本工具主要帮助你完成以下几件事：

  1. 还原 96 孔板：把 A1～H12 孔位显示出来，方便核对样本、基因、Ct 和熔解温度（Tm）。
  2. 快速查看结果：自动汇总各个样本、各个基因的 Ct Mean 和相对表达量。
  3. 发现异常：提示未测出孔、复孔波动、多熔解峰、基线异常和仪器软件标记等问题。
  4. 处理可疑孔位：手动或批量标记剔除孔位，然后重新计算 Ct Mean、Ct SD、RQ 和质控结果。
  5. 导出分析资料：保存 Excel 汇总表、96 孔板图片以及剔除孔位方案。

重要说明：这是一个辅助整理和自动初筛工具，不会替代仪器原生分析软件，也不能仅凭导出表格证明扩增产物正确。最终仍应结合扩增曲线、熔解曲线、阴性对照和实验记录判断。

02

打开工具并导入 PCR 文件

2.1 如何打开

找到文件 PCR导出文件可视化分析工具_纯JavaScript版.html，直接双击，使用浏览器打开即可。

本版本的 PCR 分析核心和 Excel 解析组件都已写入 HTML 文件，不需要安装 Python、Pyodide 或单独启动服务器，可以离线使用。建议使用较新的 Chrome 或 Edge 浏览器，以获得更好的文件选择、全屏和保存体验。

打开后，页面左上方显示 “JavaScript版已就绪”，就表示程序已完成初始化。若显示加载失败，可以点击 “查看加载日志” 查看原因，并使用 “复制日志” 保存故障信息。

2.2 支持哪些数据文件

可以导入：

  • .xls、.xlsx、.xlsm
  • .csv、.txt

但文件扩展名正确不代表一定能识别。导出的结果表至少需要能识别以下四类信息：

必需信息 常见列名 用途
孔位 Well Position、Well 确定 A1～H12 的位置
样本名 Sample Name、Sample 识别不同样本
靶基因 Target Name、Target 识别不同基因
Ct 值 Ct、Cq、CP 进行 Ct 汇总和质控

程序还可根据源文件实际提供的列，额外读取 Ct Mean、Ct SD、RQ、Tm、Omit、Amp Status、Cq Conf、各类软件 Flag、Baseline 等信息。如果原文件没有某个字段，对应功能可能无法完整评价。

对于包含多个工作表的 Excel，程序会尝试自动找到合适的 PCR 结果表，并在能够识别时读取 Melt Curve Result 工作表中的多个熔解峰信息。

2.3 导入文件的步骤

方法一：拖拽导入

  1. 在电脑中找到 PCR 仪器导出的文件。
  2. 将文件拖到左上方 “将PCR导出的文件拖到这里” 区域。
  3. 松开鼠标，程序开始分析。

方法二：手动选择

  1. 点击 “选择PCR文件”。
  2. 找到并选中导出文件。
  3. 等待结果显示。

导入成功后，页面会自动生成 96 孔板和各类分析结果。状态栏还会提示纳入计算的孔数、未测出孔数、多峰孔数及异常组合数量。

提示：本工具读取文件进行分析，不会直接修改你电脑上的原始 PCR 文件。

03

认识主界面

工具的桌面端主界面主要分为左右两个区域。

3.1 左侧：文件导入及 96 孔板

左侧通常固定显示文件信息和孔板。孔板按 A～H 行、1～12 列 排列，每个有数据的孔位可显示：

  • 孔位编号，如 A1、B6；
  • 样本名称（Sample Name）；
  • 靶基因名称（Target Name）；
  • Ct 数值及能够读取的 Tm 数值。

孔板颜色和边框用于提示不同情况：

显示效果 含义
浅绿色 未出现孔板图例中列出的主要问题
浅红色 Ct 为 Undetermined 或未获得有效 Ct
紫色边框 存在 MTP（多个熔解峰）标记
深红色边框 存在 NOAMP 或 EXPFAIL 标记
浅橙色 存在 HIGHSD，或重算后复孔 Ct SD 超过相应阈值
浅灰色 已手动标记剔除的孔位
较深灰色 原始 ABI/QuantStudio 文件中已经设置 Omit 的孔位

同一孔可以同时存在多种问题。孔板颜色只是快捷提示，不能代替点击孔位查看详细信息，也不代表已经通过全部质控项目。

3.2 右侧：三个主要页面

页面 主要作用 什么时候看
实验信息 查看样本数、基因数、异常孔统计及仪器导出信息 导入文件后首先查看
结果表格 查看 Ct、RQ、复孔、Tm、基线、Flag 和综合质控 需要分析或导出数据时
质控结论 查看自动给出的本次实验风险概况、原因与建议 决定是否需要复核或剔除数据时

在桌面端，右侧可以独立滚动；在较窄屏幕上，左右区域可能改为上下排列。

04

最常用的基础操作

4.1 查看某个孔的具体信息

在左侧 96 孔板上，鼠标左键单击某个有数据的孔。

程序会弹出孔位信息窗口。你可以查看该孔的 Sample Name、Target Name、Ct、是否 Undetermined、Amp Status、Cq Conf、Amp Score、Tm 或多峰信息、软件 Flag，以及 Baseline Start/End 等字段（以原始文件实际包含的内容为准）。

例如：看到 A1 孔显示 Ct 为 Undetermined，可以左键点击 A1，进一步核对其扩增状态、有无熔解峰、是否被仪器标记为 Omit。

4.2 放大 96 孔板

点击左侧工具栏的 “放大孔板”，可把孔板放大显示，方便核对密集的样本名和各孔数值。

放大后仍可以点击孔位查看信息，并通过右侧操作按钮进行剔除、重新计算或导出。点击 “缩小孔板” 或按 Esc 返回普通界面。

4.3 查看 Ct Mean

  1. 在右侧点击 “结果表格”。
  2. 选择 “Ct Mean” 子页面。
  3. 查看按样本与基因排列的平均 Ct 数据。

表格通常以 行为样本、列为基因，能快速比较某个样本的不同基因，或同一基因在不同样本中的 Ct。

点击 “复制Ct Mean数值” 可复制数值矩阵，直接粘贴到 Excel 等软件中。复制内容不包含样本名和基因名；没有有效结果的位置保留空单元格，所以粘贴前要确认行列顺序。

4.4 查看 RQ 或相对表达量

在 “结果表格” → “RQ / 相对表达量” 中查看结果。刚导入文件时，程序默认选择 2^(-ΔCt) 模式。这个模式需要选好内参基因，具体用法见第 7 节。

点击 “复制RQ数值” 可直接复制数值矩阵，同样不包括样本名和基因名。

4.5 先看本次实验是否有明显异常

点击右侧 “质控结论”，查看本次实验的总体提示、异常统计，以及具体的问题、可能原因和建议操作。

推荐先找到红色异常组合，再检查黄色需要复核的组合；对于提示的问题，回到原仪器软件查看扩增和熔解曲线。

05

进一步查看各类质控表格

右侧 “结果表格” 下方提供 9 个子页面。初学者不需要一次看完，建议先看 Ct Mean、复孔 Ct 质控和综合质控，再按需要查看其他页面。

子页面 主要显示什么 主要用于解决什么问题
Ct Mean 各 Sample × Target 的平均 Ct 快速整理 Ct 结果
RQ / 相对表达量 原文件 RQ 或重新计算的相对表达量 后续相对定量分析
Undetermined / MTP汇总 原始数据中各组合的未测出孔和 MTP 数量 快速定位检出及熔解峰问题
复孔Ct质控 各复孔 Ct、Ct Mean、Ct SD、孔间差、未测出数量 检查技术复孔重复性
Tm质控 各复孔 Tm、主峰均值、主峰孔间差及多峰数 检查熔解表现是否一致
复孔Ct+Tm质控 同一处联合呈现 Ct 和 Tm 同时查看扩增和产物特异性线索
基线质控 自动基线、Baseline Start 和 Baseline End 等 发现可疑基线设置
软件标记 仪器导出的原生 Flag 和扩增状态 查看仪器已发现的问题
综合质控 对多个指标进行联合风险提示 快速找到需要优先复核的组合

5.1 两种查看方式：横向总览和按 Sample 分表

复孔 Ct、Tm、Ct+Tm、软件标记及综合质控页面可以切换两种视图：

  • 横向总览：把样本和基因集中在一张大表格中，适合整体比较。
  • 按Sample分表：每个样本各有一张表，基因逐行排列，适合仔细检查一个样本的技术复孔。

建议：如果一次检测的样本或基因很多，先用横向总览找到异常，再切换按 Sample 分表查看细节。

5.2 复孔 Ct 质控怎么用

假设一个基因做了 3 个技术复孔。程序可以列出这 3 个孔的 Ct，并给出：

  • Ct Mean：用于概括这一组的平均 Ct。
  • Ct SD：反映这一组复孔的波动程度。一般来说，越大表示越不一致。
  • 孔间差：这一组有效 Ct 中最大值减最小值。
  • Undetermined 孔数：这一组有多少孔未获得有效 Ct。

例如，同一基因的 3 个孔分别为 23.10、23.25 和 30.50。此时不建议只看 Ct Mean，应优先检查第三个孔的原始扩增曲线、加样记录和 Tm，再决定是否剔除。

5.3 Tm 质控怎么用

Tm 是熔解温度。对于使用熔解曲线分析的实验，程序会检查单孔是否存在多个峰、技术复孔的主峰 Tm 是否相近，以及同一靶基因在不同样本间的主峰 Tm 是否出现明显差异。

MTP（Multiple Tm Peaks）表示多个熔解峰。这提示需要进一步复核产物特异性，但不能仅凭这一项就确定是哪一种非特异性产物。

如果源文件有 Melt Curve Result 工作表，程序会尽量读取完整的峰列表以及可提供的峰高；如果没有，就使用结果表中能识别到的 Tm 列。没有导出 Tm 时，本工具无法凭空还原熔解曲线。

5.4 软件标记怎么用

有些仪器导出文件会带有 NOAMP、EXPFAIL、MTP、HIGHSD、CTFAIL、CQCONF 等 Flag。软件标记页面负责集中显示这些信息，方便追查问题。

特别注意：如果某个 Flag 列没有导出，页面会提示“未读取到”。这表示文件缺少对应信息，不等于该项质控正常。

5.5 综合质控怎么用

综合质控会合并 Ct、复孔、Ct SD、Tm、基线和软件标记的信息，并采用其中较高的风险等级作为该样本与基因组合的最终风险提示。

  • 绿色：当前已读取指标未触发明显异常规则。
  • 黄色：至少有一项需要复核。
  • 红色：至少有一项达到程序定义的明显异常规则。

鼠标停留在带有异常提示的表格单元格上，可以查看具体原因。绿色不等于实验绝对成功，红色也不是自动判定整次实验作废。 应结合原始曲线和实验设计处理。

5.6 原始异常数量与重新计算后的质控不同

Undetermined / MTP汇总 页面有一项非常重要的特点：它统计的是首次导入的原始数据，不随手动剔除和重新计算改变。因此，你可以用它回溯一开始到底有哪些孔存在未测出或 MTP 标记。

这个汇总表支持点击列标题进行升序或降序排列，方便快速找出问题较多的样本或基因。

06

在孔板上剔除异常孔并重新计算

这是本工具最需要认真操作的进阶功能。

6.1 先记住一个关键区别

“标记剔除”不等于“已经重新计算”。

使用右键或批量按钮时，程序只是先记录你想排除的孔，并用灰色标识。此时结果表和质控结论仍可能是上一次计算的内容。必须再点击左侧的“重新计算”，新的剔除方案才会真正应用。

6.2 手动剔除一个异常孔

假设 A1、A2、A3 为同一样本、同一基因的 3 个复孔，检查后确认 A3 不适合纳入后续计算：

  1. 在 96 孔板中找到 A3。
  2. 鼠标右键单击 A3，孔位会变为手动排除状态。
  3. 检查其他孔位，有需要可以继续右键标记。
  4. 点击工具栏 “重新计算”。
  5. 查看更新后的 Ct Mean、Ct SD、RQ、综合质控和质控结论。

如果只是误点，在重新计算之前再次右键点击该孔，即可取消该孔的排除标记。如果已经计算过，也可以再次右键恢复该孔，之后再点一次 “重新计算”。

程序重新计算时保留原孔位的样本名和基因名，方便回溯；已被排除的孔不参与当前计算及对应质控。

6.3 批量剔除未测出孔

点击 “剔除未测出”。

这个按钮实际按以下条件匹配孔位：原生 NOAMP Flag、原生 EXPFAIL Flag，或者 Amp Status = No Amp。符合条件的孔会被批量标记为剔除，但仍需手动点击 “重新计算” 才能应用。

注意：它并不是简单地搜索所有 Ct = Undetermined 的孔。如果源文件只显示 Undetermined、没有相应 Flag 或 Amp Status，就可能无法被这个批量按钮选中。这种情况应先核对孔位，再使用右键手动剔除。

6.4 批量剔除离群复孔

点击 “剔除离群复孔”，程序会查找源文件中被 OUTLIERRG 标记的孔，批量设置手动排除标记，随后仍需点击 “重新计算”。

这项功能依赖导出文件中的 OUTLIERRG 信息，不是根据 Ct SD 自动推断并剔除所有离群值。若仪器没有导出该标记，可能没有可批量操作的孔。

6.5 重置剔除方案

点击 “重置”，程序会清除手动选择的剔除标记。

  • 如果之前还没有应用过剔除方案，重置后标记就会清空。
  • 如果之前已经进行过重新计算，重置只会先恢复孔板标记；还要再次点击“重新计算”，原先被排除的孔才会重新参与分析。

6.6 ABI Omit 与手动剔除的区别

如果原始仪器文件中某孔的 Omit 已设为真，程序会自动把这个孔排除在计算之外，并在孔板上用较深灰色标记。

这种原始 Omit 状态无法通过本工具右键恢复，“重置”也不会取消 ABI Omit。若想让它重新纳入分析，需要回到原仪器软件取消 Omit，再重新导出并导入文件。

6.7 重新计算后具体会更新什么

点击 “重新计算” 后，工具会用当前仍纳入分析的复孔重新生成有关统计结果，包括相应组合的 Ct Mean、Ct SD、RQ（按照所选的计算模式）、质控等级、质控结论和孔板的部分颜色显示。

如果剔除之后某个样本与基因组合已经没有有效数据，Ct/RQ 表格仍保留原来的样本与基因位置，对应结果可能留空。若某个组合经过排除后只剩 1 个有效 Ct，则无法计算常规的复孔样本标准差。

对于原文件 RQ 模式要特别注意：只要某个样本与基因组合受 Omit 或手动剔除影响，程序会重新汇总该组 Ct，而不沿用该组旧的原文件 RQ。因此，这种组合的“直接读取原文件RQ”结果可能为空。需要表达量时，可在确认实验设计合理后选择 2^(-ΔCt) 或 2^(-ΔΔCt) 重新计算。

07

计算相对表达量（RQ）

本功能位于 “结果表格” 页面顶部。计算模式有三种：

模式 计算或读取方式 常见用途
直接读取原文件RQ 使用源 PCR 文件已包含的 RQ 数据 查看仪器原本输出的 RQ
计算 2^(-ΔCt) 根据目标基因和内参基因 Ct Mean 计算 对每个样本做内参归一化
计算 2^(-ΔΔCt) 再相对于一个校准样本进行归一化 比较处理组与对照组的相对变化

7.1 选择内参基因

程序会尝试从文件识别内参基因。如果不能读取相应设定，可能优先选择 SPDEF 或当前数据中的第一个基因。自动选择仅供初始显示，务必确认其确实是你实验使用的内参。

例如，实验实际使用 GAPDH 或 ACTB 作为内参，就要在 “内参基因” 下拉列表中选择正确的基因。

7.2 模式一：直接读取原文件 RQ

选择 “直接读取原文件RQ”。此时无需选择内参或校准样本。

该模式只展示原文件中可用的 RQ，不会自行判断原仪器软件选择的内参、校准样本和标准曲线设置是否符合你的研究设计。如果原文件没有 RQ，则对应单元格可能为空。

7.3 模式二：计算 2^(-ΔCt)

选择 “计算 2^(-ΔCt)”，并选定内参基因。程序按以下公式计算：

ΔCt = 目标基因 Ct Mean − 内参基因 Ct Mean
相对表达量 = 2^(−ΔCt)

例如：目标基因 Ct Mean 为 25，内参 Ct Mean 为 20，则 ΔCt = 5，计算结果为 2^(-5) = 0.03125。

如果一个样本缺少有效的内参 Ct Mean，程序无法对该样本完成这项归一化，对应结果会留空。

7.4 模式三：计算 2^(-ΔΔCt)

选择 “计算 2^(-ΔΔCt)”，然后分别设置：

  1. 内参基因：例如 GAPDH、ACTB 等实际使用的内参。
  2. 校准样本：例如对照组中具有代表性、扩增质量可靠的样本。

程序按以下公式计算：

样本 ΔCt = 样本目标基因 Ct Mean − 样本内参 Ct Mean
校准样本 ΔCt = 校准样本目标基因 Ct Mean − 校准样本内参 Ct Mean
ΔΔCt = 样本 ΔCt − 校准样本 ΔCt
相对表达量 = 2^(−ΔΔCt)

举例：

项目 目标基因 Ct Mean 内参 Ct Mean ΔCt
校准样本 24 20 4
待测样本 22 20 2

待测样本的 ΔΔCt = 2 − 4 = −2，因此相对表达量为 2^2 = 4。在符合相对定量方法前提的情况下，可理解为相对于该校准样本的 4 倍。

注意：本工具选择的是某一个具体的 Sample Name 作为校准样本，并不会自动先计算多个对照样本的组均值，再以组均值进行归一化。如果研究方案需要以对照组均值为基准，应另行核对和处理。

7.5 修改设置后如何得到新结果

选择模式、内参基因或校准样本后，页面会触发重新计算；也可以点击 “应用并计算” 手动刷新。新的相对表达量会显示在 RQ 页面中。

特别提醒：如果源文件的 Experiment Type 为 Standard Curve（标准曲线实验），这里的 2^(-ΔCt) 和 2^(-ΔΔCt) 只是本工具基于 Ct Mean 额外计算的数值，并不等同于 ABI 标准曲线法输出的 Quantity。

08

保存结果与恢复剔除方案

8.1 导出全部结果到 Excel

  1. 切换到右侧 “结果表格”。
  2. 修改顶部的 “导出文件名”（可选）。
  3. 点击 “导出全部表格Excel”。
  4. 在浏览器下载目录查看生成的 .xlsx 文件。

导出的 Excel 包括 Ct Mean、RQ、原始 Undetermined/MTP 汇总、Ct 和 Tm 复孔质控、基线质控、软件 Flag、综合质控、质控结论、异常组合、孔位扩展信息，以及手动剔除和 ABI Omit 孔位记录等工作表。

注意：如果你改变了孔位剔除状态但尚未点击“重新计算”，这个 Excel 导出按钮会暂时不可用。请先完成重新计算，确保导出的是当前已应用的结果。

8.2 一键导出孔板图和剔除方案

点击左侧 “一键导出”，在弹出的窗口中设置文件名，并选择需要保存的内容：

  • 导出剔除方案 JSON：保存当前手动选择的孔位及对应的样本、基因信息。
  • PNG 图片：导出孔板位图，适合查看、插入 Word 或 PowerPoint。
  • SVG 图片：导出矢量孔板图，适合放大或后续编辑。
  • 不导出图片：只保存上方勾选的 JSON 方案。

点击 “开始导出” 执行。必须至少选择一种导出内容。

注意：左侧的 “一键导出”不包含 Excel 汇总表。若还需要完整数据表，请另外使用右侧的 “导出全部表格Excel”。

8.3 为什么要保存 JSON 剔除方案

JSON 文件可以理解为一张“这次我排除了哪些孔”的记录单。它不会包含完整的原始 PCR 数据，而是记录剔除孔的位置、样本名和靶基因名等信息，便于以后恢复相同的剔除选择。

例如，你今天人工核对曲线后排除了 A3、B7、C2，可以把方案保存起来。下次重新打开同一份原始 PCR 文件时，不必逐个重新右键选择这些孔。

8.4 如何导入之前保存的剔除方案

  1. 先导入相应的原始 PCR 文件。
  2. 点击左侧 “导入剔除”。
  3. 选择以前保存的 .json 文件。
  4. 程序会检查孔位以及文件中记录的样本名、基因名是否匹配。
  5. 核对灰色孔位后，点击 “重新计算”，正式应用这套方案。

如果 JSON 中的某孔在当前文件不存在，或者它的样本、基因与保存时不一致，程序会跳过这些不匹配记录；源文件中已经 ABI Omit 的孔也不再重复手动排除。因此，最好把剔除方案用于原来那份文件或布局完全相同的文件。

8.5 文件会保存到哪里

  • 在支持相关本地文件访问功能的浏览器中，程序可能优先打开原始 PCR 文件所在目录的保存窗口。
  • 其他情况下采用浏览器的常规下载方式，通常保存到默认下载文件夹，具体取决于浏览器设置。

不要把“优先定位原文件目录”理解为“必然自动保存在原文件旁边”；最终位置以文件选择器或浏览器下载设置为准。

如何看懂常见异常提示

下面是常见提示的通俗解释。它们表示需要核对哪些问题，不代表程序已经确定异常的生物学原因。

提示 通俗理解 建议首先核对
Undetermined 没有得到有效 Ct 扩增曲线、模板量、阳性对照、反应体系
NOAMP 仪器判断没有可检测的扩增 Amp Status、原始曲线、阴阳性对照
EXPFAIL 仪器的指数扩增识别算法未能可靠工作 基线、阈值、扩增曲线形态
MTP 出现多个熔解峰 熔解曲线、引物特异性、必要时跑胶
HIGHSD 仪器标记复孔波动较大 复孔 Ct、移液误差、气泡、加样记录
OUTLIERRG 仪器标记某复孔组存在离群孔 该孔与其他复孔的 Ct、Tm 和曲线
CTFAIL Ct 计算异常 原始曲线及相关算法标记
BLFAIL 基线计算失败 Baseline Start/End、扩增曲线
THOLDFAIL 阈值判定失败 阈值是否落在合适的扩增区间
CQCONF Cq/Ct 置信度相关质量标记 Cq Conf 数值和扩增曲线
AMPNC 阴性对照中出现扩增信号 污染、非特异性扩增、NTC 设置
Amp Status = Inconclusive 仪器对扩增状态判断不明确 扩增曲线、Cq Conf、其他 Flag
Omit 仪器端已经决定不纳入该孔 检查是否确实应该排除

9.1 对照孔的特殊情况

  • NTC（无模板对照）：理想情况下不应有特异性扩增。如果 NTC 出现可计算的 Ct，程序会提示重点核查。对于没有扩增的 NTC，NOAMP 等某些软件标记并不会简单地当成严重异常。
  • 无逆转录对照（No RT）：用于辅助排查基因组 DNA 或污染等问题。程序会根据样本名称初步识别这类样本，请使用清晰的命名，例如 No RT 或 no-RT。

如果你没有按仪器 Task 或样本名称标明对照类型，工具可能无法正确判断它是哪种对照。请先核对原始实验设计，不能让自动识别结果替代实验记录。

以下为本版本代码内使用的自动提示阈值，并非所有实验室和所有试剂体系通用的强制标准。不同平台、染料、引物体系和检测目的可能需要不同的判断标准。

指标 黄色或需要复核的范围 红色或明显异常的范围
Ct Mean 偏高 35 < Ct ≤ 38 Ct > 38
Ct Mean 偏低 5 ≤ Ct < 8 Ct < 5
Ct SD 0.5 < SD ≤ 1 SD > 1
同组复孔主峰 Tm 孔间差 1℃ < 差值 ≤ 2℃ 差值 > 2℃
同一基因跨样本主峰 Tm 跨度 — 跨度 > 2℃
Baseline End 偏早 2 < End ≤ 5 End ≤ 2
Baseline End 偏晚 30 ≤ End < 35 End ≥ 35
同组 Baseline End 差异 差异 > 5 个循环 本项规则不单独设红色阈值

特别提醒：Ct SD、Tm 差值等阈值用于辅助筛查，不要只因为超过阈值就不看原始曲线而直接剔除数据。

常见问题与使用建议

Q1. 文件选进去了，却提示找不到 PCR 结果表？

说明程序未能在工作簿中识别同时包含 孔位、样本名、基因名和 Ct/Cq 的结果表。请确认导出的是逐孔 PCR Results 数据，而不只是图片、统计汇总页或不包含孔位的简化结果文件。

Q2. 为什么有些 Tm、Flag 或 RQ 是空的？

通常是原始导出文件没有相应字段，或者这些字段无法被识别。本工具不会自动从原始荧光曲线重新提取所有参数。需要完整的熔解峰和软件质控信息时，应尽量使用包含有关字段的仪器导出模板。

Q3. 右键剔除后，Ct Mean 为什么没变？

因为你只是改变了待应用的孔位标记，还没有点击 “重新计算”。请先核对灰色孔位，再执行重新计算。

Q4. 点击“剔除未测出”后，为什么仍有 Undetermined？

该批量按钮按 NOAMP、EXPFAIL 或 Amp Status = No Amp 筛选，并不覆盖所有仅以 Undetermined 文本表示的孔。剩余孔位需要结合原始记录单独判断，必要时右键剔除。

Q5. 点击“剔除离群复孔”后没有变化，是不是程序失效？

不一定。它只批量识别源文件提供的 OUTLIERRG Flag。没有这种标记、或匹配孔已被标记时，就可能没有新孔需要剔除。

Q6. 为什么某些孔怎么都恢复不了？

这些孔可能是原始文件中已经设置 Omit 的孔。请在 ABI/QuantStudio 原软件里取消 Omit，并重新导出；工具中的“重置”只针对手动剔除。

Q7. 为什么重新计算后某些 Ct SD 或 RQ 变空？

可能是因为有效复孔不足、内参缺失、校准样本缺失，或者该组合的原文件 RQ 已因剔除而不再沿用。先检查被保留的孔位数量、计算模式和内参选择。

Q8. 为什么“质控结论”和原始 Undetermined/MTP 汇总的数量不完全一致？

因为质控结论基于当前已应用的剔除结果，而 Undetermined / MTP汇总 固定保留第一次导入文件时的原始统计。两者统计口径不同。

Q9. 绿色代表可以直接拿去发表文章吗？

不代表。绿色仅说明当前可读取字段未触发该工具的主要自动异常规则。是否能够用于正式分析，还要结合扩增效率、特异性、对照设置、检测限和实验 SOP。

Q10. 可以直接修改 Excel 原始文件吗？

本工具的剔除操作只影响网页中的分析结果，不会写回或改动导入的 PCR 原文件。如需留存，应导出新的 Excel 结果、孔板图片和 JSON 剔除方案。

一次完整分析的推荐流程

第一次使用时，可以直接照下面的顺序完成一次分析：

  1. 打开 HTML 工具，确认顶部显示 “JavaScript版已就绪”。
  2. 拖入 PCR 导出文件，确认孔板和实验信息加载成功。
  3. 查看“实验信息”，核对文件名、样本数、基因数、纳入计算孔数以及 Omit 情况。
  4. 查看“Ct Mean”和“复孔Ct质控”，初步判断哪些样本与基因组合有明显波动。
  5. 查看“Tm质控”“软件标记”和“综合质控”，结合右侧 “质控结论” 找出需要重点复核的孔。
  6. 返回原仪器软件查看异常孔的扩增曲线和熔解曲线，结合实验记录判断是否应排除。
  7. 在 96 孔板上右键标记需剔除的孔，或使用批量按钮完成初步标记。
  8. 点击“重新计算”，确认 Ct Mean、Ct SD、RQ 和质控结论已更新。
  9. 检查“内参基因”“RQ数据来源”和必要时的“校准样本”，确保计算方式符合实验设计。
  10. 导出全部表格 Excel；如需保留孔板图和剔除选择，再点击左侧 “一键导出” 保存 PNG/SVG 和 JSON。

建议每次保留三类文件：原始仪器导出数据、质控汇总 Excel、剔除孔位 JSON。若需归档孔板位置和异常标记，可额外保存 PNG/SVG 图片。这样以后复查结果时，既能追溯原始数据，也能确认当时具体排除了哪些孔。
